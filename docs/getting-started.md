# Getting Started with cSharp-now

## Overview

This repository explores classic Gang of Four design patterns and how modern C# features can provide cleaner, more idiomatic alternatives.

## How to Navigate

The repository is organized into three main categories:

### 1. **Creational Patterns** (`/Creational`)
Patterns that deal with object creation mechanisms.
- Singleton
- Factory
- Builder
- Prototype
- Abstract Factory

### 2. **Structural Patterns** (`/Structural`)
Patterns that deal with object composition and relationships.
- Adapter
- Decorator
- Facade
- Proxy
- And more...

### 3. **Behavioral Patterns** (`/Behavioral`)
Patterns that focus on communication between objects.
- Observer
- Strategy
- Command
- State
- And more...

## Pattern Structure

Each pattern directory typically contains:

- `README.md` - Pattern explanation and use cases
- `Classic/` - Traditional Gang of Four implementation
- `Modern/` - Modern C# alternative using contemporary features
- `Comparison.md` - Trade-offs and when to use each approach
- `Examples/` - Real-world code examples
