# Behavioral Patterns

Behavioral patterns focus on communication between objects, defining how objects interact and distribute responsibility.

## Patterns in This Directory

- **Observer** - Notifying multiple objects about state changes
- **Strategy** - Encapsulating interchangeable algorithms
- **Command** - Encapsulating requests as objects
- **State** - Altering behavior when internal state changes
- **Template Method** - Defining algorithm skeleton in base class
- **Iterator** - Sequentially accessing elements without exposing structure
- **Visitor** - Adding operations to object structures
- **Chain of Responsibility** - Passing requests along a chain
- **Interpreter** - Defining grammar and interpretation
- **Mediator** - Centralizing complex communications
- **Memento** - Capturing and restoring object state
